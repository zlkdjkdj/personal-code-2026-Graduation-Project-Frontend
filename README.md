# 🎓 2026 Graduation Project - Frontend Prototype (Learn-Time)

> 본 리포지토리는 **2026학년도 졸업과제**의 기초적인 **프론트엔드 화면 프로토타입**입니다.  
> 이 프로토타입을 기반으로 사용자 경험(UX) 및 주요 인터랙션 흐름을 검증하고, 이를 토대로 본 졸업과제 시스템을 완성도 있게 발전시켰습니다.

<br />

## 🌟 프로젝트 개요

**Learn-Time**은 학습(Education)과 신체 건강(Fitness), 그리고 커뮤니티(Community) 요소를 융합하여 사용자의 지속적인 성장을 돕는 **성장 관리 대시보드 플랫폼**입니다.

이 프로토타입은 핵심 화면(대시보드, 학습 및 운동 관리, 커뮤니티, 인증 흐름)의 레이아웃과 UI 컴포넌트를 설계하여 사용자 경험을 사전 테스트하기 위해 제작되었습니다.

---

## 🎨 주요 화면 및 기능

프로토타입은 크게 아래와 같은 기능 단위를 포함하고 있습니다.

### 1. 🏠 Landing & Auth (홈 & 인증)
* **메인 랜딩 페이지**: 서비스 소개 및 핵심 피처 카테고리 요약
* **로그인 & 회원가입**: 유효성 검사 규칙(이메일 형식, 비밀번호 강도 요구사항)이 실시간으로 검증되는 인터랙티브 인증 폼 구현

### 2. 📊 Main Dashboard (성장 관리 모드)
* **학습 관리 (Education)**: 학습 교재 및 계획 설정, AI 학습 가이드(할 일 관리), 학습 이력 수동 기록 및 공부 추천 제안 기능
* **건강 관리 (Fitness)**: 오늘 소모 칼로리 및 운동 시간 트래킹, 신체 부위별 운동 기록, 최근 7일간의 체중 변화 추이 시각화 그래프
* **커뮤니티 (Community)**: 동료들과 공부 시간 및 랭킹 점수를 공유할 수 있는 랭킹 보드 및 커뮤니티 피드 레이아웃

### 3. ⚙️ Dashboard Layout (탭 모드)
* 날씨 위젯, 일정 등록/관리(My Schedule), 효율성 등급(Efficiency Grade) 차트 위젯 및 테마 토글(Dark/Light) 기능을 제공하는 사이드바 기반 대시보드 레이아웃

## ⚠️ 프로토타입의 부족한 점 (Limitations)

본 프로토타입은 초기 아이디어 구체화용으로 설계되어 다음과 같은 기술적/디자인적 부족함이 있었습니다.

* **프로젝트 파이프라인 연동 부재**: 프론트엔드 단독 구조로 작성되어 데이터가 영속적으로 관리되지 않고, 백엔드 및 실시간 외부 데이터와의 통합 파이프라인이 매끄럽게 연결되어 있지 않습니다.
* **단조로운 데이터 시각화**: 차트 및 진행률 바 등의 통계 기능이 CSS 기반의 정적 구현에 머물러 있어, 복잡한 지표 변화나 일일 데이터의 변동 추이를 한눈에 직관적으로 시각화하는 데 한계가 있습니다.
* **프로토타입 수준의 디자인 레이아웃**: 핵심 피처 배치에 중점을 두어 전체적인 UI/UX 디자인의 통일성 및 마이크로 인터랙션의 정교함이 부족했습니다.
* **정보의 가독성 및 탐색성 저하**: 컴포넌트 간 정보 배치의 밀도가 높아 모바일이나 태블릿 환경 등 화면 크기가 달라질 때 대시보드 지표의 가독성이 감소하는 현상이 있습니다.
* **정적 API 및 모의 데이터 의존**: AI 코칭 메시지 및 학습/건강 콘텐츠가 실시간 갱신 없이 정적인 더미 데이터에 의존하여 유동적이지 못했습니다.

## 🚀 기획 및 프론트엔드 발전 반영 사항 (Advanced Implementations)

상기 프로토타입의 부족한 점들을 면밀히 분석하고 전면적으로 개선하여, 실제 졸업과제 최종 버전에서는 다음과 같이 **기획 및 프론트엔드 고도화**를 이루어 냈습니다.

* **⚙️ 엔드 투 엔드 프로젝트 파이프라인 고도화**:
  * Spring Boot 백엔드 서버 및 MySQL 데이터베이스와의 실시간 API 연동을 구축하고 RESTful 파이프라인을 고도화하여, 유저 상태 데이터가 유실되지 않고 안전하게 송수신되도록 개발을 완료했습니다.
* **📊 시각화 체계의 명확화 (뚜렷한 데이터 시각화)**:
  * 기존의 단순 CSS 레이아웃에서 벗어나 `Recharts` 라이브러리를 전면 도입하였습니다. 사용자의 누적 학습량 및 체중 변화 등의 추이를 부드러운 애니메이션 차트와 실시간 반응형 툴팁으로 구현하여 시각적 전달력을 높였습니다.
* **🎨 전체적인 디자인 개선 및 테마 고도화**:
  * 다크 모드 및 라이트 모드 전환 시 발생할 수 있는 레이아웃 깨짐을 방지하고 일관된 테마 컬러 토큰을 정의해 프리미엄 디자인 시스템을 구축했으며, 사용자 행동에 반응하는 마이크로 인터랙션 모션 효과를 추가했습니다.
* **👀 가독성 및 반응형 레이아웃 최적화 (가독성 증가)**:
  * 각 대시보드 카드의 크기 조정 및 타이포그래피 정리를 통하여 텍스트 가독성을 크게 늘렸으며, 다양한 브라우저 및 디바이스 환경에서 균형감 있게 정보가 표시되도록 레이아웃 정렬을 재설계했습니다.
* **🤖 실시간 AI API 분석 및 전역 상태(Zustand) 도입**:
  * OpenAI/Gemini API를 실제 파이프라인에 연결하여 사용자의 학습 로그에 맞는 실시간 AI 맞춤 코칭을 제공하도록 기획을 실현시켰으며, Zustand를 사용한 전역 상태 관리로 데이터 통신 지연율을 줄였습니다.

## 🚀 시작 가이드 (Getting Started)

### 1. 패키지 설치
이 프로젝트는 `pnpm` 패키지 매니저를 사용합니다.
```bash
pnpm install
```

### 2. 로컬 개발 서버 실행
```bash
pnpm run dev
```

### 3. 빌드 및 프로덕션 확인
```bash
pnpm run build
pnpm run preview
```
